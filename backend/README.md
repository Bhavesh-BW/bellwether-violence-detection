# 🚨 Violence Detection System (CPU-Based)

## 📌 Overview

This project implements a **real-time violence detection system** using
deep learning.

Supports: - Image - Video - Webcam

Classifies: Violence / Non-Violence

## 🎯 Objectives

-   Detect violent activities
-   Real-time CPU inference
-   Flexible pipeline

## 🧠 Model

-   ResNet18 (Pretrained)
-   Transfer Learning

## 📦 Dataset

RLVS Dataset

## 🧪 Training

Epochs: 5\
Batch Size: 16\
Optimizer: Adam

## 🏗️ Architecture

Input → Motion Detection → Model → Buffer → Output

## ⚡ Performance

CPU-based, real-time capable

## 🚀 Future Work

-   Better models
-   Alerts
-   Edge deployment

## 🏁 Conclusion

Lightweight, production-style system for violence detection.
